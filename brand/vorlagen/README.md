# Beschilderungs-Vorlagen — V1

Stand 24.11.2026. Word-Vorlagen (`.dotx`) für die Türschilder im A6-Format (A4 quer,
Seitenrand 0, Arial, Logo als PNG eingebettet). Ein Doppelklick auf die Datei öffnet ein
neues Dokument; die Vorlage selbst bleibt unverändert.

| Datei | Inhalt |
|---|---|
| `2026_Vorlage_Beschilderung_Sonnhalde_Einzeln_A6_Einerzimmer_V1.dotx` | Ein Schild, Einerzimmer: Name, Nr. |
| `2026_Vorlage_Beschilderung_Sonnhalde_Einzeln_A6_Doppelzimmer_V1.dotx` | Ein Schild, Doppelzimmer: zwei Namen («Fenster», «Tür»), Nr. |
| `2026_Vorlage_Beschilderung_Sonnhalde_Kacheln_A6_Einerzimmer_V1.dotx` | Vier Schilder (2 × 2) auf einer Seite, Einerzimmer |
| `2026_Vorlage_Beschilderung_Sonnhalde_Kacheln_A6_Doppelzimmer_V1.dotx` | Vier Schilder (2 × 2) auf einer Seite, Doppelzimmer |
| `2026_Vorlage_Beschilderung_Sonnhalde_Einzeln_A6_Buero_V1.dotx` | Ein Schild, Büro: Bezeichnung und bis zu drei Personen mit Arbeitstagen |
| `vorschau/` | Vorschaubilder (PNG) der fünf Vorlagen, gerendert mit LibreOffice |

## Hinweise

- Die gelbe und cyanfarbene Markierung hebt die Platzhalter hervor.
- Die Büro-Vorlage enthielt im Original echte Namen, Funktionen und Arbeitstage. Sie sind
  hier durch Platzhalter ersetzt («Vorname Nachname», «Arbeitstage»), weil die Seite über
  GitHub Pages öffentlich erreichbar ist.
- Die Dokument-Eigenschaften (Autor, zuletzt geändert von) sind auf «Sonnhalde» gesetzt.
- Im Original der Vorlage «Kacheln Doppelzimmer» ist bei «Nr. 1339» nur «133» markiert, die
  letzte Ziffer nicht. Nicht verändert.
- Dateinamen: `2026_Vorlage_Beschilderung_Sonnhalde_<Layout>_A6_<Zimmerart>_V<n>.dotx`; bei
  jeder neuen Fassung zählt die Versionsnummer hoch.
- Gleicher Inhalt im Sonnhalde-Design-System (Artifact), Gruppe `Vorlagen-Beschilderung`.
