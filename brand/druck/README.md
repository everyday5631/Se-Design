# Logos — Druck (PDF, 4C und Pantone)

26 PDF, erzeugt aus den EPS-Dateien des Grafikers («01 Logos Druck», Unterordner `4C`
und `Pantone`). EPS lässt sich hier nicht speichern; die Umwandlung mit Ghostscript
(`pdfwrite`) ändert weder Pfade noch Farben. Original-EPS liegen im Brand-Paket für das
Repo `Se-Design` (`brand/original/`).

- **4C-Dateien** sind in DeviceCMYK, zum Beispiel Sonnengelb 0 / 35 / 92 / 0 und
  Anthrazit 0 / 0 / 0 / 90.
- **Pantone-Dateien** tragen die Sonderfarben (Separation), Sonnengelb als
  Pantone 129U / 137C.
- **Namen:** `<Logo>-<Fassung>-<4C|Pantone>.pdf`; `Logo-hor` = «Nur Sonnhalde»,
  `Logo-Zusatz-hor` und `Logo-Zusatz-ver` = mit «Pflege- und Betreuungszentrum».
- **Fassungen in 4C:** `farbig`, `auf-blau`, `auf-gelb`, `neg`; dazu `schwarz` bei der
  Bildmarke und `graustufen` bei «Zusatz hor». **In Pantone:** `farbig`, `auf-blau`,
  `auf-gelb` und die gelbe Bildmarke; es gibt keine Pantone-Fassung «neg».
- **Beiliegende Grafiker-PDF:** Für `Sonnhalde-Bildmarke-gelb-4C` und
  `Sonnhalde-Logo-hor-auf-blau-4C` hat der Grafiker zusätzlich je ein eigenes PDF
  geliefert; diese liegen im Brand-Paket unter `brand/original/`.
- **Einfarbig** mit Schwarz ist nur die Bildmarke (`schwarz`) vorhanden; «graustufen»
  gibt es als PDF nur horizontal mit Zusatz (vertikal nur als SVG).
- **Weisse Dateien** (`neg`) erscheinen auf weissem Grund leer; das ist richtig.
